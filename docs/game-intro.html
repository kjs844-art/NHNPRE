1. 한 줄 소개

낡은 빌라의 야간 원격 관제사가 되어 CCTV 화면 속 '이상 현상'을 찾아 보고하는 관찰 심리 호러 게임 — 단, 마지막 밤에는 카메라가 당신을 비춘다.

2. 게임 방법

목표

매일 밤 00:00부터 06:00까지(실시간 90~150초) CCTV를 순찰하며 이상 현상을 찾아 보고하고, 5일 밤의 수습 근무를 무사히 마친다.

조작 (마우스만 사용)

행동방법
카메라 전환화면 하단의 CAM 버튼 클릭
이상 현상 보고우측 하단 [보고] 버튼 → 이상 유형 선택
음소거우측 상단 스피커 아이콘

규칙

  • 이상 유형: 물체 이동 · 물체 소실 · 침입자 · 조명 이상 · 개방 · 화면 왜곡 (밤이 지날수록 해금)
  • 이상을 방치하면 침식도가 상승하고, 침입자는 카메라 쪽으로 점점 다가온다.
  • 정확한 보고는 침식도를 회복시킨다. 없는 것을 보고(오탐)하면 기록이 남고 침식도가 오른다.
  • 화면 속 변화는 당신이 보고 있지 않을 때 일어난다. 순찰 리듬이 생존의 열쇠.

종료 조건

조건결과
침식도 100% 도달배드엔딩 — 관제실 문 앞에 무언가 서 있다
5일 밤 완료트루엔딩 — CAM 07이 켜지고, 진실이 드러난다

로컬 실행 시:

git clone https://github.com/kjs844-art/NHNPRE.git
cd NHNPRE && npm install && npm run dev
  • 권장 환경: 데스크톱 Chrome/Edge 최신 버전, 마우스, 소리 켜기
  • 유료 라이선스·설치·계정 불필요. 전 에셋 코드 생성(외부 파일 0개).
  • 진행 상황은 브라우저에 자동 저장되며(밤 단위), 이어하기가 가능하다.

4. 특징 요약

  • 적응형 AI 디렉터: 플레이어의 탐지 정확도·속도를 실시간 추적해 스폰 간격, 이상 유형의 미묘함, 동시 발생 수를 조정. 침식도가 높으면 '자비 규칙'이 발동해 좌절을 방지.
  • 규칙이 곧 공포: "변화는 안 볼 때 일어난다"는 게임 규칙이 마지막 밤의 반전 연출로 그대로 회수된다.
  • 5일의 서사: 사내 메신저로 진행되는 박 주임과의 대화, 밤마다 쌓이는 위화감, 그리고 근무자 등록에 입력한 당신의 이름이 마지막 보고서에 나타난다.
  • 플레이 타임: 전체 클리어 약 10~12분 (밤 선택으로 구간 재플레이 가능)
