# 이상 없음 (ALL CLEAR) — 게임 디자인 문서

> NHN GAME × AI HACKATHON (NAN2026) 사전 과제 제출작
> 장르: 심리 호러 / 관찰 추리 · 플랫폼: 웹 브라우저 (데스크톱 마우스) · 인원: 1인

---

## 1. 한 줄 소개

낡은 빌라의 야간 원격 관제사가 되어 CCTV 화면 속 '이상 현상'을 찾아 보고하라 —
단, 마지막 밤에는 카메라가 당신을 비춘다.

## 2. 핵심 재미 (심사자가 60초 안에 느껴야 할 것)

1. **관찰 긴장감**: 방금 전까지 멀쩡했던 화면에서 무언가 달라진다. 액자가 사라지고, 문이 열려 있고, 복도 끝에 실루엣이 서 있다.
2. **판단 압박**: 보고가 맞으면 해결, 틀리면 신뢰도 하락. "정말 뭔가 달라졌나?" 스스로 기억을 의심하게 만든다.
3. **방치의 공포**: 이상을 놓치면 사라지지 않는다. 실루엣은 카메라 쪽으로 **점점 다가온다**.

## 3. 스토리 프레임

- 주인공은 '한빛빌라 통합관제' 야간 아르바이트 **신입**. 출근 첫날부터 회사 메신저로 선임 **박 주임**의 지시를 받는다.
- 전임 관제사는 3주 전 무단결근 후 연락 두절이라고 한다.
- 5일 밤의 근무. 밤마다 이상 현상은 늘어나고, 박 주임의 말투는 미묘하게 어긋나기 시작한다.

### 반전 (5일차)

5일차 자정, 존재하지 않아야 할 **CAM 07 — 관제실** 피드가 켜진다. 화면 속엔 모니터를 바라보는 누군가의 뒷모습.
박 주임: "신입, 오늘 관제실 근무는 재택이잖아. …지금 거기 누구야?"
플레이어가 CAM 07을 확대하는 순간 화면 속 인물이 천천히 뒤를 돌아본다.
마지막 보고 — 대상: **전임 관제사 (3주 전 실종)**. 접수 완료 메시지:
"신고가 접수되었습니다. 대상: 실종자 ○○○. …오늘도 '이상 없음'으로 보고되었습니다."
**당신이 감시하던 것이 아니라, 당신이 감시당하고 있었다. 당신은 실종된 전임자다.**
(1편 「잔상」과 같은 세계관 — '자신이 실종자였다' 모티프의 확장)

## 4. 코어 루프

```
카메라 전환 → 화면 관찰 → 변화 감지 → [보고] 버튼 → 이상 유형 선택
   ↑                                        ↓ 정답: 해결 + 안정도 회복
   └──────── 다음 카메라 순찰 ←──────────── ↓ 오답: 신뢰도 하락
                                            ↓ 방치: 침식도 상승 (실루엣 에스컬레이션)
```

- 화면은 항상 **1개 카메라 풀뷰** (FNAF 방식). 하단 버튼으로 전환, 전환 시 노이즈 트랜지션.
- 밤은 게임 내 00:00 → 06:00 (실시간 90~150초).

## 5. 이상 유형 (보고 시 선택지)

| 유형 | 설명 | 판정 |
|---|---|---|
| 물체 이동 | 소품이 다른 위치로 | 시각 비교 |
| 물체 소실 | 액자·화분 등이 사라짐 | 시각 비교 |
| 침입자 | 어두운 실루엣 등장 | 즉시 식별 가능, 방치 시 접근 |
| 조명 이상 | 소등, 색 변화, 점멸 | 즉시 식별 가능 |
| 개방 | 닫혀 있어야 할 문/창이 열림 | 시각 비교 |
| 화면 왜곡 | 노이즈, 기울어짐 (3일차 해금) | 즉시 식별 가능 |

## 6. 자원 및 실패 조건

- **침식도 (0→100%)**: 이상 방치 시 상승. 100% → 배드엔딩 (화면이 전부 노이즈로 덮이고, 마지막 프레임에 실루엣이 관제실 문 앞에 서 있다).
- **신뢰도 (오탐 카운트)**: 밤당 오탐 3회면 침식도 대폭 상승 + 박 주임 경고 메시지.
- 이상을 해결하면 침식도 소폭 회복.

## 7. AI 디렉터 (알고리즘형 적응 난이도) — AI 활용 기술문서의 핵심 소재

플레이어 퍼포먼스를 실시간 추적해 난이도를 조정하는 결정론적 시스템:

- **입력 신호**: 최근 탐지 정확도(적중/오탐), 평균 탐지 소요 시간, 현재 침식도
- **출력 파라미터**:
  - 스폰 간격 (잘 잡을수록 짧아짐)
  - 미묘함 가중치 (잘 잡을수록 '물체 이동' 같은 미세 변화 비중↑, 못 잡으면 '침입자' 같은 명확한 변화 비중↑)
  - 동시 이상 상한 (밤 진행도 + 실력에 비례)
  - **자비 규칙**: 침식도 70% 초과 시 스폰 지연 — 좌절 방지
- 모든 판단은 시드 가능한 RNG 위에서 동작 (테스트 재현성)

## 8. 밤 구성

| 밤 | 카메라 | 길이 | 특징 |
|---|---|---|---|
| 1 | 3 | 90s | 튜토리얼. 명확한 이상만, 박 주임이 조작 안내 |
| 2 | 4 | 105s | 소실/개방 추가 |
| 3 | 5 | 120s | 화면 왜곡 해금, 동시 2건 |
| 4 | 6 | 135s | 전 유형, 동시 3건, 박 주임 메시지가 어긋나기 시작 |
| 5 | 6+1 | 150s | CAM 07 이벤트 → 반전 엔딩 시퀀스 |

## 9. 카메라(방) 목록

1. **로비** — 우편함, 소파, 안내판, 유리문
2. **4층 복도** — 401~404호 문, 천장등, 소화기
3. **402호 거실** — (공실) 가구 실루엣, 액자, 창문
4. **지하 주차장** — 기둥, 차량 실루엣, 셔터
5. **엘리베이터** — 내부 거울, 층수 표시
6. **옥상** — 물탱크, 난간, 출입문
7. **관제실 (CAM 07)** — 5일차 전용. 책상, 모니터 6대, 앉아 있는 뒷모습

모든 방은 코드 드로잉(기하 실루엣 + 그라디언트 + 필름그레인/비네트)으로 제작 — 외부 에셋 0개.

## 10. 연출·사운드

- WebAudio 합성: 앰비언트 드론, 카메라 전환 노이즈 블립, 보고 접수음, 오탐 버저, 침식도 고조 시 심장박동, 반전 스팅어. 외부 파일 없음.
- 시각: CRT 스캔라인, 비네트, 노이즈 오버레이, 카메라 타임스탬프(REC ● 표시), 실루엣 에스컬레이션 3단계(멀리→중간→카메라 앞).

## 11. 완성도 요소

- localStorage 진행 저장(밤 단위 이어하기), 음소거 토글, 결말 2종(배드/트루), 크레딧, 키보드 없이 마우스만으로 플레이 가능, 데스크톱 권장 안내.

## 12. 기술 스택

- React 19 + TypeScript + Phaser 3 (렌더링) + Vite. 순수 정적 빌드 → GitHub Pages.
- 상태: React(메타/UI) ↔ Phaser(장면) EventBus 브리지. 이상 현상 엔진은 프레임워크 독립 순수 TS 모듈(단위 테스트 가능).
